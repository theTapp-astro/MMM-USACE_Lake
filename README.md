# MMM-USACE_Lake

Displays live data from the USACE CWMS API.

## Features

- Lake Elevation
- Outflow
- Storage
- Water Temperature
- Automatic Refresh
- Multiple reservoirs

## Installation

cd ~/MagicMirror/modules
git clone https://github.com/theTapp-astro/MMM-USACE_Lake.git

cd MMM-USACE_Lake
npm install

You'll need to configure for your lake. Data about the API can be found here: 
https://cwms-data.usace.army.mil/cwms-data/swagger-ui
